This project aims to support non-technical users in their everyday email processes.
We are not a spam filter and are not aimed to catch every atak. We want to answer the question "Is it safe to go ahead?".

*Privacy
Emails are checked only on your device. Email content never leaves the phone. We do not read your mail.

*Status
This is a prototype in testing. Only Gmail is supported for now.

*Reporting security issues
Please do not open a public issue. Email admin@miramail.me instead, we are very open to collaboration.
