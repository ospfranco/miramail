# Very well known domains: the domain-age check (and its Certificate Transparency lookup) is skipped for them.
# Source of truth for both apps. Edit here, then run: python3 scripts/update-known-domains.py

# How to read this file: one registrable domain (the eTLD+1) per line, lowercase. Subdomains are covered
# automatically (mail.google.com counts as google.com). Run scripts/update-known-domains.py after editing.
#
# What belongs here: domains of very well known organisations that only they control, so a domain-age lookup would
# tell the user nothing. What never belongs here: anything where outsiders can get a subdomain or host content
# (blogspot.com, github.io, herokuapp.com, netlify.app, amazonaws.com, sharepoint.com, wordpress.com, ...)
# because 'well-known' would then vouch for a phishing page. The update script refuses those.
